## Overview

Circa models the tonal character of classic BBD delay chips with voltage-controlled time, diffusion, and modulation controls that produce warm, organic echoes ideal for guitar and synthesizer processing.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Audio Damage Circa** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **BBD Model** | Discrete transistor-ladder simulation of classic bucket-brigade delay ICs |
| **Wow and Flutter** | Tape-style pitch instability modulation with rate and depth |
| **Diffusion** | Variable diffusion network for washy, reverb-like echo textures |
| **Self-Oscillation** | Push feedback above unity for creative pitch-climbing resonance |
